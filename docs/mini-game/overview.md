# 小游戏SDK概览

猕猴桃小游戏SDK提供统一的对接方案，支持微信、抖音、快手等小游戏平台。

## 支持平台

| 平台 | 前端对接 | 说明 |
|------|---------|------|
| [微信小游戏](./wechat/frontend-guide.md) | JavaScript SDK | 支持微信登录、支付、订阅消息、游戏圈等 |
| [抖音小游戏](./douyin/frontend-guide.md) | JavaScript SDK | 支持抖音登录、虚拟支付、客服等 |
| [快手小游戏](./kuaishou/frontend-guide.md) | JavaScript SDK | 支持快手登录、支付、快捷方式、视频广告等 |

## 整体架构

小游戏对接分为两部分：

1. **前端对接**：在小游戏工程中引入 JS SDK，调用登录、支付、上报等接口
2. **服务端对接**：CP 服务端与猕猴桃服务端交互，包括登录验证、订单发货回调、数据上报等

### 通用文档

以下内容为所有平台通用：

- [服务端对接](./common/server-integration.md) — 猕猴桃调用CP接口的订单发货回调
- [接口加签说明](./common/signing.md) — 所有接口的签名生成规则
- [数据上报](./common/data-reporting.md) — 角色信息、充值数据等上报接口

### 接入流程

1. 联系运营获取 `mhtAppId` 及 SDK 资源文件
2. 引入 SDK 并配置 `mhtAppId`
3. 配置环境和游戏状态（正式/测试）
4. 接入必接接口：登录、支付、安全检查、角色上报
5. 按需接入选接接口：客服、游戏圈、视频广告等
6. 服务端对接：登录验证、订单发货回调
7. 服务端接入数据上报接口
